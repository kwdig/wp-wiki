wp-wiki 1.0.9
=====================
PHP/CSSを直接変更しやすい、最小限のクラシックテーマです。
サイトエディター用のブロックテーマではありません。投稿・固定ページのブロックエディターには対応します。

インストール（マルチサイト）
1. サイトネットワーク管理 → テーマ → テーマを追加 → テーマのアップロード。
2. wp-wiki.zip をアップロードしてインストール。
3. ネットワークで有効化（各サイトで選択できる状態にします）。
4. 使用したい子サイトの管理画面 → 外観 → テーマ → wp-wiki を有効化。
通常のWordPressでは、外観 → テーマ → 新規追加からアップロードできます。

最初の設定
・外観 → メニューでメニューを作り「ヘッダーメニュー」「フッターメニュー」に割り当て。
・外観 → カスタマイズ → サイト基本情報でロゴを設定。
・投稿／固定ページの「アイキャッチ画像」で画像を設定。
・設定 → 表示設定 → 1ページに表示する最大投稿数を設定。
  記事数がこの数を超えると、記事一覧に数字のページネーションが表示されます。
・トップページを固定ページにする場合は、表示設定でホームページと投稿ページを指定。

主な編集箇所
style.css : 冒頭のCSS変数で色・横幅・角丸・余白の設定を変更。
header.php / footer.php : ヘッダーとフッター。
index.php : 記事一覧、カテゴリー、タグ、検索結果。
template-parts/content-card.php : 一覧の各記事カード。
single.php : 投稿詳細。
page.php : 固定ページ。
functions.php : WordPress機能とCSS/JSの読み込み。
assets/navigation.js : スマホメニューの開閉。
assets/editor.css : 投稿エディター内の表示。

対応機能
・公開済みの固定ページをサイドバーに自動表示。ウィジェット設定の有無に関係なく表示し、マルチサイトでは現在のサイトのページだけを表示します。
・一覧の数字ページネーション、記事内の改ページ、前後の記事、コメントのページ分割。
・記事一覧にアイキャッチ画像を表示。投稿・固定ページの詳細画像は本文に挿入してください。
・PCは本文＋右サイドバーの2カラム、768px以下は本文→サイドバーの1カラム。スマホメニュー、レスポンシブ画像。
・カテゴリー／タグ／年月別アーカイブ／検索／404／コメント。
・タイトルタグ、フィード、カスタムロゴ、ブロックエディター、レスポンシブ埋め込み。
・キーボード操作、スキップリンク、開閉状態の読み上げ。
・外部ライブラリ、外部フォント、外部通信なし。

カスタマイズの注意
・派生テーマを配布する場合、フォルダ名とstyle.cssのTheme Nameを変更。
  PHP関数のwpwiki_接頭辞、CSS/JSハンドル、Text Domainも固有名へ変更してください。
・:rootの--spaceは追加スタイル用の余白変数です。標準レイアウトの余白は各ルールで指定しています。
・theme.jsonは含めていません。ブロックテーマへ拡張する際は別途追加してください。
・公開前に実際のWordPress上で投稿・画像・メニュー・コメントを設定して確認してください。
・WordPress.org公式ディレクトリの審査済みテーマではありません。

1.1.0 の変更
・日本語向けのシステムフォントと1.85の行間を採用。外部フォントを取得しません。
・右サイドバーを追加。外観 → ウィジェット → 右サイドバーから編集できます。
・ウィジェット未設定時は「検索」「最近の記事」「カテゴリー」を表示します。
・スマホではサイドバーを本文の下に表示します。
・記事一覧は縦並び。PCではアイキャッチ画像を左、本文を右に配置します。
・style.css末尾の--width-sidebarと--gap-columnsでサイドバー幅とカラム間隔を変更できます。
・screenshot.pngは管理画面用のデザイン見本です。記事や画像が自動登録されるものではありません。
1.1.1 の変更：ヘッダー検索を追加。虫眼鏡付き検索欄と検索ボタンを一体化。スマホではヘッダー内で全幅表示。

1.1.2 の変更：フッターに「テーマ制作：KWMine」を追加。https://kwmine.com/ を新しいタブで開きます。

1.1.3：カテゴリー／タグの一覧見出しは名称のみ。検索欄を横長の一体型へ変更、青いボタンを維持。フッター表記はTheme by KWMine。


1.2.0：高速化と配布用の汎用化
・テーマCSSをHTML内に出力して、初期表示を待たせるCSS通信を削減。
  子テーマでは親テーマCSSの後に子テーマCSSを出力します。
・ヘッダーメニューが設定されている場合だけメニュー用JavaScriptを読み込みます。
・記事一覧の画像サイズ指定をレイアウトに合わせ、先頭画像は優先読み込み、後続は遅延読み込み。
・サーバーが対応している場合、新しくアップロードするJPEGの縮小画像をWebPで生成します。
  既存画像は自動変換しません。WordPress標準のレスポンシブ画像を使用します。
  特定サイトの画像ファイル名やサンプル画像への依存はありません。
・検索向けの説明文をサイトのキャッチフレーズ、記事本文／抜粋、カテゴリー／タグ説明から生成。
  パスワード保護された記事本文は説明文に使用しません。
  Yoast SEO、Rank Math、All in One SEO、SEOPress有効時はテーマ側の説明文を出力しません。
  その他のSEOプラグインを使う場合は子テーマ等で以下を追加してください。
  add_filter( 'wpwiki_enable_meta_description', '__return_false' );
  WebP生成を止めたい場合：
  add_filter( 'wpwiki_enable_webp', '__return_false' );
・Theme by KWMineの制作者リンクは維持しています。

高速化について
・サーバー側キャッシュ設定（.htaccess等）とアクセス解析の停止はテーマに含みません。
  これらは利用するサイト／サーバーで別途設定してください。
・KWMineで行った既存画像のWebP変換データは同梱していません。
・PageSpeedの結果は画像、プラグイン、サーバー等によって変わるため、100点を保証しません。
・ZIPにはテーマファイルのみを含み、投稿データ、認証情報、アクセス解析IDは含みません。


1.2.1：詳細ページの画像重複を修正
・投稿・固定ページの本文前にアイキャッチを自動表示する処理を削除。
・一覧のアイキャッチ画像は引き続き表示します。
・詳細ページに画像を表示する場合は、本文に画像ブロック等で挿入してください。


1.2.3：記事一覧・記事詳細のカテゴリーとタグをタイトル直下の日付の横に配置。サイドバー検索の入力欄とボタンを横一列に修正。


派生テーマについて
wp-wiki 1.0.0：WordPress Blank 1.2.3をベースに作成。カテゴリー・タグのタイトル直下表示と、サイドバー検索の横一列表示を継承。GPL-2.0-or-later。


Wiki風デザイン：左カテゴリー・淡いグレーの背景・白い本文パネル・コンパクトな記事一覧。スマートフォンのカテゴリーボタンに対応。

関連記事：記事末尾に同じカテゴリーの記事を優先し、共通タグの記事で補完して最大5件表示。現在の記事・非公開記事・重複を除外し、該当記事がなければ表示しません。

1.0.2：本文・記事一覧・サイドバー・フッターのリンクに下線を付け、色だけに依存せず識別できるよう修正。
